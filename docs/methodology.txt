THE LEMON MARKET -- MODEL AND CODE REVIEW NOTES
===============================================

Purpose of this document
------------------------
This describes exactly what the interactive page "The Lemon Market" computes,
the math behind it, and how the "Your Screening Skill" control is applied, so a
second person can check both the methodology and the code. Code excerpts below
are copied verbatim from the page source (a single HTML file; "html line N"
gives the line number in that file). Everything is plain JavaScript with no
libraries. Sections 1-3 are the math, 4 is the simulation, 5 is screening,
6-7 are outputs and parameters, 8 is validation, 9-10 are limitations and open
items.

Source of the model: Connor, "Deception is Amplified by Default", Boson Cutter
(Substack), Apr 19 2026:
  https://bosoncutter.substack.com/p/deception-is-amplified-by-default
Sections 1 and the w = 1 case of Section 3 reproduce the essay's results. The
generalization to w < 1 (Section 3) and the screening mapping (Section 5) are
ours, not the essay's.


1. THE MODEL (FROM THE ESSAY)
-----------------------------
Each person is in one of two states:
  A = Available (job hunting / single and looking)
  U = Unavailable (hired / in a relationship)

Each person has a true value V and an observed value O (how good they look:
resume, profile). Define the "truth ratio" X = V/O.
  X < 1  : overselling (looks better than they are)
  X = 1  : as advertised
  X > 1  : underselling (a hidden gem)

Transitions form a two-state continuous-time Markov chain (CTMC):
  A -> U at hiring rate  beta_O   (depends only on OBSERVED value O)
  U -> A at firing rate  alpha_V  (depends on TRUE value V; revealed over time)

Stationary probability of being available, for one person:
  P(A) = alpha_V / (alpha_V + beta_O)

Assumption (essay): liars are fired faster,  alpha_V = alpha_O / X,  where
alpha_O is the firing rate of an as-advertised person (X = 1). Mean dwell times
are T_U = 1/alpha_V and T_A = 1/beta_O. Define the single market parameter

  gamma = T_A / T_U (at X = 1) = alpha_O / beta_O

("how much time even an honest person spends on the market relative to off it").
Then, for a person with truth ratio x:

  P(A | x) = alpha_V / (alpha_V + beta_O) = gamma / (gamma + x)        (1)

Check: (alpha_O/x) / (alpha_O/x + beta_O) = alpha_O / (alpha_O + beta_O x)
= gamma / (gamma + x).

The essay conditions on a fixed observed value O, so beta_O is the same for
everyone in the pool being examined; only alpha differs (through X).


2. NORMALIZATION USED IN THE SIMULATION
---------------------------------------
Time is measured in units where beta_O = 1 (BETA = 1 in the code). Then
alpha_O = gamma, and a person with truth ratio x, once taken, leaves the taken
state at rate gamma / x. O is held fixed (O = 1), so V = X. Every person starts
in state A at t = 0 (the essay's initial condition), so the pool at t = 0 is
the unskewed population, and skew builds as people cycle.


3. CLOSED-FORM RESULTS (USED FOR THE "THEORY:" LINES AND DASHED REFERENCE)
--------------------------------------------------------------------------
Population of truth ratios: X ~ Uniform(a, b) with a = 1 - w, b = 1 + w, density
1/(2w). The essay uses w = 1, i.e. Uniform(0, 2). w < 1 is how we model
screening (Section 5). Let

  L = ln( (1 + w + gamma) / (1 - w + gamma) )

Availability (integrate (1) over the population):
  P(A) = (1/(2w)) * integral_a^b gamma/(gamma+x) dx = gamma * L / (2w)      (2)

Distribution of X among the available (Bayes):
  p(x | A) = [gamma/(gamma+x)] / (2w P(A)) = 1 / ((gamma + x) * L)

Share of the available pool that is overselling (X < 1):
  P(X<1 | A) = integral_a^1 dx / ((gamma+x) L) = ln((1+gamma)/(1-w+gamma)) / L   (3)

Mean truth ratio of the available pool:
  E[X | A] = (1/L) integral_a^b x/(gamma+x) dx
           = (1/L) integral_a^b (1 - gamma/(gamma+x)) dx = (2w - gamma L) / L   (4)

Mean truth ratio of the taken pool ("poaching" view). P(U | x) = x/(gamma+x),
P(U) = 1 - P(A), and x^2/(gamma+x) = x - gamma + gamma^2/(gamma+x), so
  integral_a^b x^2/(gamma+x) dx = (b^2-a^2)/2 - gamma(b-a) + gamma^2 L
                                = 2w - 2 w gamma + gamma^2 L
  E[X | U] = (1 - gamma + gamma^2 L / (2w)) / (1 - P(A))                     (5)

At w = 1 these reduce exactly to the essay's formulas:
  P(A)       = (gamma/2) ln((gamma+2)/gamma)
  P(X<1 | A) = ln((gamma+1)/gamma) / ln((gamma+2)/gamma)
  E[X | A]   = 2/ln((gamma+2)/gamma) - gamma
  E[X | U]   = [1 - gamma + (gamma^2/2) ln((gamma+2)/gamma)]
               / [1 - (gamma/2) ln((gamma+2)/gamma)]

Code (equations 2-5):
[html line 379]
function theory(gamma, w){
  var L = Math.log((1+w+gamma)/(1-w+gamma));
  var PA = gamma*L/(2*w);
  return {
    PA: PA,
    PXlt1_A: Math.log((1+gamma)/(1-w+gamma))/L,
    EXA: (2*w - gamma*L)/L,
    EXU: (1 - gamma + gamma*gamma*L/(2*w)) / (1 - PA)
  };
}

The page passes w = spreadWidth(screening) into theory(), so the theory lines
always describe the same population the simulation is drawing from.


4. THE MONTE CARLO SIMULATION
-----------------------------
This is a direct simulation of the CTMC (not Markov-chain Monte Carlo
inference): N agents (default 260), each with a fixed truth ratio drawn once,
each evolving as an independent two-state Markov chain.

Draw of truth ratios (u ~ Uniform(0,2); w from Section 5; floor of 0.02 only to
avoid division by zero in gamma/x):
[html line 328]
function genAgents(n, screening){
  var w = spreadWidth(screening);
  var arr=[];
  for(var i=0;i<n;i++){
    var u = Math.random()*2;
    var x = Math.max(1 + (u-1)*w, 0.02);
    arr.push({x:x, s:'A', flip:-999});
  }
  return arr;
}

State reset (all agents start Available; history cleared):
[html line 339]
function resetSim(){
  state.agents = genAgents(state.n, state.screening);
  state.t = 0; state.tick=0;
  state.history = [];
  state.recordEvery = 0.15;
  state.lastRecordT = -999;
  recordHistory();
}

One time step of length dt = 0.05. Each agent flips with probability
(rate * dt): Available -> Taken with prob BETA*dt, Taken -> Available with prob
(gamma/x)*dt:
[html line 348]
function simTick(dt){
  var agents = state.agents, g = state.gamma, tick = state.tick;
  for(var i=0;i<agents.length;i++){
    var a = agents[i];
    if(a.s==='A'){
      if(Math.random() < BETA*dt){ a.s='U'; a.flip=tick; }
    } else if(Math.random() < (g/a.x)*dt){ a.s='A'; a.flip=tick; }
  }
  state.t += dt; state.tick++;
}

Playback and speed. Simulated time advanced per real second is 8 * speed
(speed 0.5 => 4 time units/s). A fractional-step accumulator keeps speed linear:

Why per-step probability = rate * dt (rather than 1 - exp(-rate*dt)): for
independent two-state chains the stationary probability of A depends only on the
RATIO of the per-step leave/enter probabilities. Using p = rate*dt keeps that
ratio exactly equal to the continuous-time rate ratio alpha/beta, so the
stationary distribution is exact as long as rate*dt <= 1; the discretization
only perturbs transient timescales (O(dt)). The 1 - exp(-rate*dt) form is
per-step exact for one step but distorts the ratio, and in testing it matched
theory WORSE (Section 8). rate*dt exceeds 1 only for x < gamma*dt (at most
0.065 at the slider's maximum gamma = 1.3); that affects at most about 3% of
agents (gamma = 1.3 with no screening), under 1% with the default screening, and
none at the defaults (worst case there: rate*dt of about 0.34 on the Dating tab).

5. HOW THE SCREENING EFFECT IS APPLIED
--------------------------------------
Essay: "If you can get better at telling when someone is lying or underselling
themselves, you'll effectively see a tighter distribution of X."

Our implementation. The slider is a validity correlation r in [0, 0.9] between
your assessment of a candidate and their true quality (0 = coin flip, 1 =
perfect). It narrows the population of truth ratios from Uniform(0,2) to
Uniform(1 - w, 1 + w) with

  w = sqrt(1 - r^2)

Rationale: if an assessment S has correlation r with true value V (bivariate
normal approximation), the fraction of variance in V left unexplained is 1 - r^2,
so the remaining spread (SD) is sqrt(1 - r^2) of the original. The SD of
Uniform(1-w, 1+w) is w/sqrt(3), i.e. proportional to w, so scaling w by
sqrt(1 - r^2) scales the spread by that factor.

  r      w = sqrt(1-r^2)   spread narrowed by
  0.00   1.000             0.0%
  0.18   0.984             1.6%    (unstructured interviews, Sackett Table 2, r_yy-corrected)
  0.31   0.951             4.9%    (page default)
  0.44   0.898             10.2%   (structured interviews, Sackett Table 2, r_yy-corrected)
  0.90   0.436             56.4%   (slider maximum)

Where it enters the code (and only here):
[html line 326]
function spreadWidth(r){ return Math.sqrt(1 - r*r); }

  (a) genAgents: every agent's fixed truth ratio is X = 1 + (u - 1) * w.
  (b) theory(gamma, w): the closed forms in Section 3 use the same w.
  (c) the histogram's pale "truth before selection" band, drawn with density
      1/(2w) over [1-w, 1+w]:
[html line 510]
var ws = spreadWidth(state.screening);
var trueDensity = 1/(2*ws);
maxDensity = Math.max(maxDensity, trueDensity)*1.08;

It does NOT change beta, alpha, gamma, or any dynamics; the effect on the
available pool comes entirely through the narrower X distribution. Changing the
slider regenerates the population and resets the simulation to t = 0.

Consequence worth stating plainly: with realistic validities (0.18-0.44) the
narrowing is only about 2-10%, so most of the skew toward oversellers remains.
That is a property of the sqrt(1 - r^2) mapping, not a bug. An earlier draft of
the page used a linear mapping w = 1 - (slider %), which shows a much larger
benefit; we changed it because the slider is now labeled as a correlation and
the linear form has no justification in terms of r.

Caveats specific to screening (please scrutinize):
  1. The 0.18 / 0.44 benchmarks are validities against JOB PERFORMANCE from
     personnel-selection meta-analysis (Sackett et al., 2022, J. Applied
     Psychology, Table 2, "Overall" employment interviews, column "Validity
     corrected for r(yy)": unstructured 0.18, structured 0.44). That column
     corrects for criterion unreliability only. The paper's headline column
     ("Current estimate of operational validity with best available
     correction", which also corrects for range restriction) gives 0.19 and
     0.42; the choice between columns moves r by at most 0.02 and changes the
     screening narrowing by well under 1 percentage point. The model uses r to shrink the spread of the claim-vs-reality
     ratio X, which is a related but not identical quantity. This is a stylized
     bridge, not something the meta-analysis supports directly.
  2. The screened population is modeled as a narrowed uniform centered on 1. The
     true conditional distribution of V given an assessment would be centered on
     an assessment-dependent mean, not on 1, and need not be uniform.
  3. Screening is applied to the whole market population (as in the essay's
     "tighter distribution of X" framing), not to a single screener's decisions.
  4. The benchmarks are hiring figures. The same slider is shown on the Dating
     tab; the page footnote says to treat it as illustrative there.

9. ASSUMPTIONS AND LIMITATIONS
------------------------------
  1. gamma is the same for every person (essay footnote 1 flags this; if alpha
     and beta vary randomly, results change substantially).
  2. alpha_V = alpha_O / X is an assumed functional form (the essay says
     "something like"); other monotone forms would change the numbers.
  3. Hiring rate does not depend on X (conditioning on a fixed O).
  4. X ~ Uniform is an assumption for tractability. Everyone starts Available.
     Closed population: no entry, exit, aging, or learning; X is fixed per
     person for all time.
  5. Finite-N noise (Section 6); reference lines are expectations.
  6. Discretization (Section 4): dt = 0.05, transient timing has O(dt) error,
     stationary results are exact except for the extreme-x cases noted.
  7. The screening mapping is a stylized construction (Section 5 caveats).
  8. Mapping from slider values to real markets (gamma) is illustrative.
  9. The model applies only to scarce, deception-rewarding matching markets
     (the essay's own scope limitation).
